# 🌐 CampusSphere

CampusSphere is an all-in-one student life platform designed to simplify and organize everyday campus activities. It combines essential tools like expense splitting, note sharing, lost & found tracking, and deadline management into a single, user-friendly web application.

---

## 🚀 Project Purpose

The main goal of CampusSphere is to solve common problems faced by students by providing:

* 📊 Easy expense management with friends
* 📚 Organized note sharing system
* 🔍 Lost & Found tracking for campus items
* ⏰ Deadline and productivity management

Instead of using multiple apps, CampusSphere provides a **centralized platform** to manage all student-related activities efficiently.

---

## 🔄 How It Works

1. User logs in using Firebase Authentication
2. Firebase provides user data (UID, email)
3. Frontend sends API requests to backend
4. Backend processes data and interacts with MongoDB
5. Data is stored/retrieved and displayed dynamically
